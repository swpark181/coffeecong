# coffeecong

WASD로 물줄기를 움직여 핸드드립 커피를 내리는 브라우저 게임입니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 물줄기 이동 |
| `Space` | 물 붓기 (5ml/s) |
| `Shift` + `Space` | 가늘게 붓기 (2.5ml/s) |
| `H` | 물 분포 히트맵 보기 |
| `F` | 기다릴 때 빨리 감기 |
| `R` | 처음부터 |

## 레시피 (원두 15g / 물 250ml)

1. **뜸 들이기**: 30~45ml로 가루 전체를 적시고 30~45초 기다리기
2. **2차 붓기**: 나선형으로 고르게 부어 누적 150ml까지
3. **3차 붓기**: 드리퍼에 고인 물이 15~50ml일 때 시작해서 누적 250ml까지

`Space`에서 손을 떼고 2초가 지나면 그 단계가 끝납니다.

## 채점 (100점)

| 항목 | 배점 | 기준 |
| --- | --- | --- |
| 고르게 붓기 | 25 | 커피 베드에 떨어진 물 양의 균일도 |
| 필터 벽 피하기 | 10 | 필터 종이 벽에 직접 부은 물의 비율 |
| 뜸 물 양 | 10 | 30~45ml |
| 뜸 커버리지 | 10 | 뜸 단계에서 적신 가루의 비율 |
| 뜸 시간 | 10 | 30~45초 |
| 2차 붓기 양 | 10 | 누적 142~158ml |
| 3차 타이밍 | 10 | 시작 시 고인 물 15~50ml |
| 최종 물 양 | 15 | 245~255ml |

등급: S 90+ / A 80+ / B 70+ / C 55+ / D

## 구조

- `index.html`: 화면 구성 (캔버스, 사이드 패널, 시작/결과 오버레이)
- `style.css`: 스타일
- `src/main.js`: 시뮬레이션, 렌더링, 채점

`index.html#debug`로 열면 `window.__cc.G`로 게임 상태를 확인할 수 있습니다 (자동 테스트용).
